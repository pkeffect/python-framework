## Architecture Overview

```
python_framework.py (Single File, ~2000 lines)
│
├── Configuration Layer (Lines 1-240)
│   ├── Constants & Theme
│   ├── load_config_file() - TOML parser
│   ├── load_plugins() - Plugin loader
│   └── TEMPLATES dict
│
├── GUI Layer (Lines 240-950)
│   ├── FrameworkGUI - Tkinter implementation
│   ├── WebGUI - HTTP fallback implementation
│   └── launch_gui() - Smart launcher
│
├── Generator Layer (Lines 950-1900)
│   ├── ProjectGenerator class
│   └── 25+ _create_* methods
│
└── CLI Layer (Lines 1900-2050)
    └── main() - Argument parsing & orchestration
```

### Design Principles

1. **Single File** - Everything in one `.py` file for portability
2. **Zero Dependencies** - Only Python stdlib
3. **Modern Python** - Type hints, pathlib, dataclasses-style
4. **Fail Gracefully** - GUI falls back to Web UI

### File Generation Pattern

All file creation follows this pattern:

```python
def _create_some_file(self) -> None:
    """Create the some.file with template content."""
    if self.dry_run:
        logger.info("Would create some.file")
        return
    
    content = """file content here"""
    
    file_path = self.output_dir / "some.file"
    file_path.write_text(content, encoding="utf-8")
    logger.info("Created some.file")
```

## Adding Features

### Adding a New CLI Argument

1. Find `argparse` setup in `main()` (~line 1960)
2. Add your argument:

```python
parser.add_argument(
    "--my-feature",
    action="store_true",
    help="Description of feature"
)
```

3. Handle it after `args = parser.parse_args()`:

```python
if args.my_feature:
    # Do something
```

### Adding a New Generated File

1. Create method in `ProjectGenerator`:

```python
def _create_my_file(self) -> None:
    """Create my custom file."""
    if self.dry_run:
        logger.info("Would create myfile.txt")
        return
    
    content = f"""
# {self.project_name} Custom File
Generated by Internode Framework
"""
    path = self.output_dir / "myfile.txt"
    path.write_text(content, encoding="utf-8")
```

2. Call it from `generate()`:

```python
def generate(self):
    # ... existing calls
    self._create_my_file()
```

### Adding a New Template

1. Add to `TEMPLATES` dictionary:

```python
TEMPLATES = {
    # ... existing
    "my_template": {
        "description": "My custom template",
        "include_configs": True,
        "include_tests": False,
        "include_docs": True,
    },
}
```

2. Optionally add template-specific logic in generator methods.

## GUI Development

### Tkinter GUI (FrameworkGUI)

Key structure:
- `__init__()` - Setup window, variables, styles
- `_apply_styles()` - Configure ttk theme
- `_create_widgets()` - Build scrollable UI
- `_generate()` - Handle generate button click

### Web UI (WebGUI)

Key structure:
- `_get_html_page()` - Returns complete HTML string
- `_create_handler()` - Creates RequestHandler class
- `do_GET()` - Serve the page
- `do_POST()` - Handle form submission

### Modifying Theme

All colors are in the `THEME` dict:

```python
THEME = {

    "accent_hover": "#ff8c5a",  # Hover state
    "border": "#4d4d4d",        # Borders
    "success": "#4caf50",       # Success messages
```

## Plugin Development

### Plugin Structure

Create `~/.internode/plugins/my_plugin.py`:

```python
"""My Plugin for Internode Framework."""

def register():
    """Required. Return plugin metadata."""
    return {
        "name": "My Plugin",
        "version": "1.0.0",
        "author": "Your Name",
    }

def post_generate(generator):
    """Optional. Called after project generation."""
    print(f"Generated: {generator.project_name}")
    print(f"Location: {generator.output_dir}")
    
    # Access generator properties:
    # generator.project_name
    # generator.output_dir
    # generator.template
    # generator.author_email
    # generator.author_handle

def post_update(generator):
    """Optional. Called after project update."""
    pass
```

### Available Hooks

| Hook | When Called | Parameters |
|------|-------------|------------|
| `register()` | Plugin load | None |
| `post_generate()` | After new project | generator |
| `post_update()` | After update mode | generator |

## Testing

### Manual Test Suite

```bash
# 1. Version check
python python_framework.py --version

# 2. Help output
python python_framework.py --help

# 3. Dry run
python python_framework.py --name Test --dry-run

# 4. Full generation (all templates)
python python_framework.py --name TestDefault --template default --no-venv
python python_framework.py --name TestMinimal --template minimal --no-venv
python python_framework.py --name TestApi --template api --no-venv
python python_framework.py --name TestCli --template cli --no-venv
python python_framework.py --name TestLib --template library --no-venv

# 5. Update mode
python python_framework.py --name TestDefault --update

# 6. GUI modes
python python_framework.py --gui
python python_framework.py --gui2

# 7. Interactive mode
python python_framework.py --interactive
```

### Verification Checks

After generating a project, verify:

```bash
cd GeneratedProject

# Python imports work
python -c "import sys; sys.path.insert(0, 'src'); import generatedproject"

# manage.py works
python manage.py --help

# Tests structure exists
ls tests/

# Configs are valid JSON/YAML
python -c "import json; json.load(open('configs/config.json'))"
```

## Common Patterns

### Logging

Use the module logger:

```python
logger.info("Creating file...")
logger.warning("Something unexpected")
logger.error("Failed to create")
```

### Path Operations

Always use `pathlib`:

```python
from pathlib import Path

file_path = self.output_dir / "subdir" / "file.txt"
file_path.parent.mkdir(parents=True, exist_ok=True)
file_path.write_text(content, encoding="utf-8")
```

### Template Strings

Use f-strings with project variables:

```python
content = f"""
# {self.project_name}
Author: {self.author_handle}
Email: {self.author_email}
"""
```
